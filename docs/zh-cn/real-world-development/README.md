通过真实场景、完整应用和共享待办事项，探索 GitHub Copilot 在软件开发生命周期中的用法。你将通过迭代规划更改、编写代码、测试行为、审查拉取请求并使用智能体管理工作。

## 场景

你是 Tailspin Toys 的新开发者。这是一家虚构公司，为桌面游戏提供众筹服务，主题与开发者有关。团队的待办事项已作为 GitHub 议题创建，随时可以开始处理，其中包括筛选和分页等功能，以及无障碍和编码标准等质量改进。

## 选择工作环境

无论在哪里工作，都可以使用 GitHub Copilot。请选择最适合开发方式的环境。每个工作坊都包含独立的设置流程，并使用相同的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手。学习 Plan 和 Autopilot 模式、说明文件、技能、自定义智能体、Playwright MCP、Agent Merge 和实用斜杠命令。

### [GitHub Copilot app][app]

在桌面应用中并行运行智能体会话、切换会话模式、协作编辑画布，并管理 GitHub 议题和拉取请求。

### [GitHub Copilot 云智能体][cloud]

将 GitHub 议题分配给异步智能体、指导其工作、监控进度并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat agent mode、MCP 服务器和自定义智能体。
