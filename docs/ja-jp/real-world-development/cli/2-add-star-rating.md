Copilot CLI をインストールして会話を試したので、次はプロジェクトに最初の変更を加えます。小さな変更から始めましょう。ゲームデータには星評価が含まれていますが、ホームページのゲームカードには表示されていません。エージェントに評価を表示してもらい、変更をレビューして、最初のプルリクエストとしてマージします。

このレッスンでは、次のことを行います。

- 機能ブランチで Copilot と会話を始めます。
- エージェントに小さな変更を依頼します。
- `/diff` で変更をレビューします。
- 転送ブラウザーでアプリを実行し、動作を確認します。
- 最初のプルリクエストを作成してマージします。

## シナリオ

Tailspin Toys の各ゲームには星評価があり、詳細ページにはすでに表示されています。一方、ホームページのゲームカードにはタイトル、カテゴリ、発行元、説明しかありません。ウォームアップとして、既存の評価を各カードに表示してもらいます。最初のセッションに適した、小規模で独立した変更です。

## 会話のしくみ

**会話**は、Copilot CLI でタスクに取り組む場所です。通常の CLI 会話では、Copilot app のように専用 worktree を作るのではなく、ターミナルで現在チェックアウトされているリポジトリと Git ブランチを使います。保存された会話から後で同じ話題を再開できます。ファイルとブランチは通常の Git 状態としてディスク上に残ります。

会話では、プロンプトとエージェントの応答、ファイルを調べて編集するためのツール操作、`/diff` で確認できる変更の 3 つを確認できます。

## 会話を始めて変更を依頼する

1. Codespace に戻ります。
2. ターミナルが開いていない場合は、<kbd>Control</kbd>+<kbd>\`</kbd> (Mac) または <kbd>Ctrl</kbd>+<kbd>\`</kbd> (Windows/Linux) を押します。
3. Copilot を起動します。

   ```bash
   copilot --yolo
   ```

4. スラッシュコマンド `/new` を入力し、<kbd>Enter</kbd> を押して新しいセッションを開始します。
5. 次のプロンプトで変更を依頼します。

   ```plaintext
   ゲーム一覧ページのゲームカードに、各ゲームの starRating を 5 点満点で表示してください。評価が null の場合は "No rating yet" と表示します。カードのレイアウトは変更せず、テストを追加して関連するチェックを実行してください。
   ```

Copilot はプロジェクトを調査し、ゲームの詳細を表示するファイルを見つけて、必要なコードを作成します。Copilot CLI を使って新しい機能を追加できました。

## 差分をレビューする

AI が生成した変更は、どんなに小さくてもマージ前にレビューします。

1. `/diff` を入力し、変更されたファイルをすべて確認します。
2. 評価がある場合は数値が表示され、`starRating` が `null` の場合は `No rating yet` と表示されることを確認します。
3. どちらの状態もテストされていることを確認します。
4. Copilot が実行したチェックの結果を確認し、失敗があれば修正を依頼します。
5. レビューが終わったら <kbd>Esc</kbd> を押して差分画面を閉じます。

> [!NOTE]
> すべての生成 AI ツールと同様、Copilot の動作は確率的であり決定論的ではありません。コードの細部は異なることがあります。特定の実装ではなく、動作を確認してください。

## 変更を確認する

コードを読むだけでなく、Codespaces の転送ブラウザーで更新した UI を確認します。

1. 次のプロンプトで Copilot にアプリを起動してもらいます。

   ```plaintext
   ブラウザーで星評価の変更を確認できるよう、アプリを起動してください。URL を教えて、サーバーは実行したままにしてください。
   ```

2. Codespaces でポート `4321` が利用可能になったら、**Open in Browser** を選択します。
3. ゲームカードに 5 点満点の評価が表示されることを確認します。
4. Copilot に戻り、次のプロンプトで起動したサーバーを停止します。

   ```plaintext
   起動した開発サーバーを停止してください。
   ```

## 最初のプルリクエストを作成してマージする

1. 次のプロンプトで、レビュー済みの変更をコミットするよう既定のエージェントに依頼します。

   ```plaintext
   レビュー済みの星評価の変更を、適切なコミットメッセージでコミットしてください。
   ```

2. `/pr create` を入力します。Copilot CLI は PR の作成時に既存のコミットをプッシュし、PR の URL を表示します。
3. Copilot CLI が表示した URL を、Mac では <kbd>Command</kbd>、Windows/Linux では <kbd>Ctrl</kbd> を押しながら選択します。
4. 変更されたファイルとチェックをレビューします。
5. 問題がなければ **Merge pull request** を選び、マージを確定します。
6. Codespace に戻り、`/exit` で Copilot CLI を終了します。
7. ローカルの `main` を更新します。

   ```bash
   git checkout main
   git pull
   ```

## まとめと次のステップ

GitHub Copilot CLI を使って、最初の変更をリリースしました。

- 機能ブランチで Copilot の会話を開始しました。
- エージェントにゲームカードの小さな変更を依頼しました。
- `/diff` で変更をレビューしました。
- 転送ブラウザーで星評価を確認しました。
- 最初のプルリクエストを作成してマージしました。
