エージェントモードの Copilot は、コードベースを調べ、変更を提案し、ファイルを編集し、コマンドを実行します。VS Code の Copilot Chat では作業の様子をリアルタイムで確認できます。各ツールの呼び出しやファイル編集を確認し、差分をインラインでレビューし、変更を受け入れたり取り消したりできます。また、エディターを離れずに追加の指示を送り、作業を修正、拡張できます。

この演習では、次のことを行います。

- アクセシビリティエージェントの作業をリアルタイムで監視します。
- 提案されたファイルの編集をレビューして受け入れます。
- セッションの途中で指示し、ハイコントラストに加えてライトモードも追加します。

## シナリオ

[演習 4][previous-lesson]で使ったアクセシビリティカスタムエージェントは、ハイコントラストモードを実装しています。作業の途中で、デザインチームから新しい依頼がありました。既定のテーマが暗すぎると感じるユーザー向けに、ライトモードも追加してほしいとのことです。会話を最初からやり直さず、進行中のセッションに追加の指示を送ります。

## Copilot の進捗を監視する

Copilot Chat ビューには、エージェントが行うファイルの調査、コマンド実行、編集が表示されます。ファイル編集は差分と **Keep** / **Undo** の操作とともに、チャット内に表示されます。

1. 演習 4 で使った Copilot Chat ビューに戻ります。
2. エージェントの作業中にチャットをスクロールし、ツールの呼び出しを確認します。ファイルの読み取りや編集、実行を求められるターミナルコマンドが表示されます。
3. エージェントがファイルを編集すると、差分がインラインで表示されます。
   - **Keep** を選択すると変更を受け入れます。
   - **Undo** を選択すると変更を取り消し、エージェントに再度作業させます。
4. チャット上部の **Files changed** を開くと、セッションで変更されたすべてのファイルを確認できます。

> [!NOTE]
> ターミナルコマンドの実行などで許可を求められる場合があります。エージェントは一時停止して **Allow** を表示します。内容を確認し、実行してよいコマンドだけを許可してください。

5. エージェントがハイコントラストモードを実装し終えるまで待ちます。最終メッセージに変更の概要が表示されます。

## エージェントにライトモードの追加を依頼する

同じ会話を続け、ライトモードの切り替えを追加します。エージェントは前の作業で触れたコンポーネント、スタイル、local storage の使い方を把握しています。

1. Copilot Chat の入力欄に次の追加プロンプトを送信します。

    ```plaintext
    よくできました。ハイコントラストの切り替えに加え、ライトモードの切り替えも追加してください。同じ方法で local storage に設定を保存し、同じ UI 領域から操作できるようにしてください。ユーザーがハイコントラストとライトモードを個別に有効にできるようにします。
    ```

2. エージェントは作成済みの変更を調べ、ライトモード用の変更を提案します。
3. ハイコントラストと同様に、追加された各編集をレビューし、**Keep** または **Undo** を選びます。
4. エージェントの進め方が希望と違う場合 (たとえば、切り替え UI を意図しない方法でリファクタリングしようとする場合) は、入力欄の横にある **Stop** ボタンで停止し、追加の説明を送信します。

> [!TIP]
> 進行中のセッションに追加の指示を送るほうが、最初からやり直すより早く済みます。「CSS を簡潔にし、セレクターを重複させず CSS 変数を使う」「設定パネルにまとめ、切り替えを 3 つに増やさない」「両方の切り替えにキーボードショートカットを追加する」のように依頼できます。

## 作業内容をレビューする

コミット前にエージェントが変更した内容を確認します。

1. VS Code で **Source Control** ビューを開きます。
2. 変更されたファイルの一覧を確認します。Astro コンポーネント、スタイル、関連テストなどが更新されているはずです。
3. 変更されたファイルをいくつか開いて差分を確認します。ARIA 属性、キーボード操作、セマンティック HTML、local storage による設定の保存など、アクセシビリティのパターンが反映されていることを確認します。
4. 問題がなければ Source Control パネルから変更をステージしてコミットします。次のレッスンで公開します。

## まとめと次のステップ

Copilot Chat のエージェントモードで作業中のセッションを監視し、ファイルの編集を確認して受け入れたり取り消したりしながら、会話を続けてタスクを拡張しました。

- エージェントの作業をリアルタイムで監視しました。
- 個別のファイル編集を受け入れ、または取り消しました。
- セッションの途中で追加の指示を送りました。
