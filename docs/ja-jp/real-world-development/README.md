現実的なシナリオ、完成したアプリケーション、共有バックログを使って、ソフトウェア開発ライフサイクル全体で GitHub Copilot を活用します。変更の計画、コードの作成、テスト、プルリクエストのレビュー、エージェントを使った作業管理を反復しながら行います。

## シナリオ

ボードゲームのクラウドファンディングを提供する架空の企業、Tailspin Toys の新しい開発者として作業します。チームのバックログは GitHub Issue として用意されています。フィルターやページネーションなどの機能開発に加え、アクセシビリティやコーディング規約の改善にも取り組みます。

## 作業環境を選ぶ

GitHub Copilot は、普段の開発環境で利用できます。開発方法に合った環境を選んでください。各ワークショップには個別のセットアップがあり、共通の Tailspin Toys シナリオを使用します。

### [GitHub Copilot CLI][cli]

ターミナルでエージェント型アシスタントを使います。Plan モードと Autopilot モード、カスタム命令、スキル、カスタムエージェント、Playwright MCP、Agent Merge、便利なスラッシュコマンドを体験します。

### [GitHub Copilot app][app]

デスクトップアプリでエージェントのセッションを並列実行し、セッションモードを切り替え、Canvas で共同作業を行い、GitHub Issue とプルリクエストを管理します。

### [GitHub Copilot cloud agent][cloud]

GitHub Issue を非同期エージェントに割り当て、作業を案内して進捗を監視し、エージェントが作成したプルリクエストをレビューします。

### [Visual Studio Code][vscode]

Visual Studio Code と GitHub Codespaces で GitHub Copilot を使います。エディターを離れずに Copilot Chat のエージェントモード、MCP サーバー、カスタムエージェントを活用します。
